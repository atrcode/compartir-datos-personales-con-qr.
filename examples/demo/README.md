# Kit de demostración: Marina Ríos

Descargá el repositorio completo, descomprimilo y abrí `index.html` en tu navegador. Los enlaces relativos funcionan con todos los archivos en esta carpeta.

La persona, organización, bio y correo son ficticios. La vCard y las firmas fueron generadas con `scripts/build_assets.py` a partir de `perfil-ficticio.json`. La página móvil es una muestra de diseño creada para la documentación; el generador no construye sitios.

El QR de `docs/images/qr-del-repositorio.png` abre el repositorio público. No es el QR definitivo de la tarjeta ficticia: esa tarjeta no está publicada. Para una entrega real, publicá el sitio primero y generá un nuevo QR con su URL estable.

El instructivo muestra Gmail web en Chrome sobre Windows. No se verificó la importación de la vCard en teléfonos ni la entrega de correos en clientes reales. El contenido de este ejemplo se distribuye con la licencia MIT del proyecto.

El retrato `marina-rios-ia.jpg` fue generado con IA para representar a esta persona ficticia. La tarjeta utiliza el archivo local; la firma carga la imagen desde la URL HTTPS pública del repositorio. El texto de la firma sigue siendo legible si el correo bloquea imágenes.
