# Entrevista de a un paso

Consultar perfil y conversación antes de cada pregunta. Recorrer este orden, omitir lo conocido, aceptar varios datos en una respuesta y hacer una sola pregunta por turno. No presentar esta tabla al usuario.

| Paso | Pregunta orientativa | Manejo |
| --- | --- | --- |
| Identidad | ¿Para qué persona o marca hacemos la tarjeta y qué nombre querés mostrar? | Necesario para identificar la entrega. |
| Rol | ¿Qué cargo o actividad querés mostrar? | Omitir si no corresponde. |
| Empresa | ¿Qué empresa u organización querés mostrar? | Opcional. |
| Logo | ¿Me pasás el logo que querés usar? | Archivo, enlace o sin logo. |
| Foto | ¿Querés sumar una foto tuya? | Pedir archivo si sí. |
| Bio | ¿Qué te gustaría contar en dos o tres líneas? | Ofrecer redacción con datos aportados. |
| WhatsApp | ¿Qué número querés publicar, con código de país? | Omitir o resolver ambigüedad antes de normalizar. |
| Email | ¿Qué email querés mostrar? | Opcional si no quiere publicarlo. |
| LinkedIn | ¿Cuál es tu enlace de LinkedIn? | Opcional. |
| Web | ¿Qué sitio web querés enlazar? | Distinguir de la nueva URL de tarjeta. |
| Otros enlaces | ¿Querés sumar otra red o enlace? | Aceptar varios con etiqueta. |
| Materiales | ¿Querés ofrecer un libro, artículo, PDF u otro material? | Si sí, pedir cada recurso, título y acción; luego preguntar si hay otro. |
| Destacado | ¿Cuál querés destacar en la firma? | Solo si hay varios; ninguno es válido. |
| Marca | ¿Tenés colores o referencia visual para respetar? | Inferir del logo o proponer diseño legible. |
| Servicio | ¿Qué servicio de correo usás: Gmail, Microsoft 365, otro? | Ayudar a identificarlo sin pedir contraseñas. |
| Aplicación | ¿Dónde lo abrís: navegador, Outlook, Apple Mail u otra aplicación? | Saltar si ya está claro. |
| Dispositivo | ¿Lo usás en Windows, Mac, Android o iPhone? | Pedir solo destinos de instalación relevantes. |
| Versión | ¿Usás Outlook nuevo o clásico? | Solo cuando cambie las instrucciones. |
| Publicación | ¿Querés alojarla en un sitio/dominio que ya tenés o crear uno nuevo? | Respetar contexto; no contratar dominio por defecto. |

Para varias personas, reutilizar identidad de marca y hosting; recopilar datos personales por separado y emitir un `.vcf` por persona. Definir páginas individuales o directorio compartido antes de generar QRs.

Resumir lo registrado antes de construir sin imponer otra aprobación si el usuario ya pidió avanzar. Si falta un dato indispensable, completar primero entregables independientes.
